# data/：从原型导出的数据表

都是从 `prototype/index.html` 运行时直接导出的（v3.1），和游戏里用的一模一样。人看的版本见 [`docs/04_数据附表.md`](../docs/04_数据附表.md)。

| 文件 | 内容 |
|---|---|
| `units.json` | 12 个可招募兵种（名称、家族、主色、走位、属性、能力、专属遗物）+ 白骨仆从 + 家族名 + 8 个开局军团 |
| `relics.json` | 94 件遗物（名称、归属兵种、是否共用 / 核心、效果） |
| `enemies.json` | 76 种人类敌军（65 常规 + 11 首领单位）：阶级、属性、骨头价值、走位、特性、外观参数 `look` |
| `enemy_traits.json` | 53 条敌军特性的名称与效果 |
| `bosses.json` | 首领原始定义、首领说明（地图卡片用）、终章三波 |
| `chapters.json` | 三章：名称、简介、起点、首领节点、集市 / 篝火名、普通战 / 精英遭遇表 |
| `patterns.json` | 16 个阵型（倍率、形状、是否固定方向） |
| `slot_items.json` | 14 种老虎机道具（类型、颜色、价格、说明） |
| `battle_items.json` | 5 种战斗道具（颜色、价格、半径、说明） |
| `map_node_types.json` | 地图节点类型（名称、颜色、11×11 图标点阵） |
| `shops.json` | 店主台词、商店说明、经济参数（价格、刷新、灵魂奖励、每战拉杆目标） |
| `constants.json` | 老虎机 / 难度 / 地图 / 布局常量、战斗约定参数 `conv`、走位、新手引导文案、兵种主色 |
| `palette.json` | 像素图色板（字符 → 颜色） |
| `pixel_art_source.json` | 现有占位像素图的字符画源（每个字符查 `palette.json`；`.` 透明） |

`look` 字段（敌人外观）：`b` 主色 · `d` 暗部 · `t` 镶边 · `h` 头饰 · `hc` 头饰色 · `w` 武器 · `o` 副手 / 背部 · `oc` 副手色 · `m` 坐骑或车 · `mc` 坐骑色 · `k` 体型 · `skin` 肤色 · `hair` 发色。
