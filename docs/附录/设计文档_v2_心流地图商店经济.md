# 亡灵老虎机 v2 设计稿：心流 · 地图 · 商店 · 经济 · Boss

> 2026-10-11 夜间版本。数值先按「锚点」定初值，再用自动模拟校准；校准后的最终数值和模拟结果写在第 11 节（以第 11 节为准）。
> 设计宗旨（用户原话）：**一段非常好的 15 分钟，一定好过无聊的一小时。** 体量宁可短，完整性和体验优先；新东西要来得快、来得密。

## 0. 一句话结构

**开局选组合 → 教学战 → 三章地图（每章：1–3 战 → 商店 → 1–3 战 → Boss → 集市）→ 终章白冠王都（连打三波）→ 通关。**
一局约 25 分钟（最短路线约 18 分钟，最长路线约 35 分钟），14–23 场战斗。

## 2. 心流曲线（整局节奏）

### 2.1 原理
心流 = 挑战略高于能力、又能被追上。做法是**锯齿形压力曲线**：

```
压力
 ▲                          Boss3      王都
 │               Boss2       /|     ___/|
 │     Boss1      /|   /\   / |    /    |
 │      /|  /\   / |  /  \ /  |   /     |
 │ /\  / | /  \_/  | /    V   |  /      |
 │/  \/  |/        |/         | /       |
 └──教学─┴────集市─┴─────集市─┴─集市──────┴→ 进度
    简单爽   1–3战升压 → 商店回落 → Boss峰值 → 集市大回落
```

- **教学战**：几乎不可能输，第一转保证出阵（「第一次拉杆就爽」）。
- **章内**：每走一个节点，敌方战力按固定倍率上涨；我方只有在商店里才会明显变强 → 连战时压力自然上升，进店后回落。
- **Boss**：本章压力最高点（模拟胜率目标 70–85%），打赢后立刻接集市（三店合一）= 全章最大的一次回落。
- **章与章之间**：基线逐章抬高，后一章开头比前一章开头更紧。
- **终章**：三波连打、中间只拉杆不进店，压力顶点；赢了直接通关。

### 2.2 「压力」用什么量
- **战力 = Σ √(生命 × 秒伤)**（兰彻斯特平方律：两军对拼时，实力 ∝ 人数² × 单兵生命 × 单兵输出；把每个单位折算成 √(生命×秒伤) 后可以直接相加比较）。
- **压力比 = 敌方战力 ÷ 我方战力**（我方按开战时、带遗物加成后的实际单位计算）。
- 实际落地时，压力比只用来看趋势；**真正的锚点是「50% 胜率线」PAR(深度)**（由自动模拟测出，见第 11 节）。每个节点的敌方战力 = PAR × 心流系数 F，F 决定这个节点「有多吃紧」。
- 胜率目标（中等策略机器人）：

| 节点 | 胜率目标 | 最终实测（第 11 节） |
|---|---|---|
| 教学战 | 100% | 100% |
| 第一章普通战 | ≥ 95% | 88–100% |
| 第二、三章普通战 | ≥ 90% | 86–100% |
| 要塞 | 85–92% | 93–97% |
| 首领 | 75–85% | 平均约 85% |
| 王都三波 | 各 75–85% | 97% / 85% / 78% |

### 2.3 时长预算
| 环节 | 单次时长 | 次数（平均路线） | 小计 |
|---|---|---|---|
| 战前拉杆 | 15–35 秒 | 18 | 约 7 分钟 |
| 自动战斗 | 20–50 秒 | 18 | 约 10 分钟 |
| 结算 + 遗物三选一 | 10 秒 | 18 | 3 分钟 |
| 商店 / 集市 | 30–60 秒 | 8 | 5 分钟 |
| **合计** | | | **约 25 分钟** |

### 2.4 「永远有新东西」的硬指标
- 每场战斗至少出现 **1 种本局没见过的人类兵种**（65 种敌人按节点编排，一局最多见到约 55 种，不重复）。
- 每个战斗节点结束都有 **1 次遗物三选一**；每个商店至少有 **1 件改变老虎机 / 兵种结构**的商品。
- 每一章换一套地貌、一套敌人、一个全新机制的 Boss。

## 3. 地图

### 3.1 形式
- **固定地图、分章显示**（每章一屏，1600×900 内放得下），整章节点一开始全部可见，Boss 和它的机制提前公示。
- 我方军旗沿道路走到下一个节点（以后做 3D 就是桌面沙盘上的棋子）。
- 节点图标直接画出奖励类型（学 Hades 门上的奖励图标）。悬停节点显示：敌军预览（兵种、数量级）、难度、奖励、连战加成。

### 3.2 节点类型
| 图标 | 节点 | 内容 |
|---|---|---|
| ⚔ | 战斗（村庄 / 营地 / 哨塔…） | 拉杆 → 战斗 → 结算（骨头 + 灵魂）→ 遗物三选一 |
| 🛡 | 要塞（精英） | 敌人更强，灵魂 ×2，遗物三选一里保证一件核心遗物 |
| ✝ | 墓园（商店） | 新兵种、符号、迁坟 |
| ⚙ | 骨匠工坊（商店） | 老虎机扩行、万能符号、阵型升级、老虎机道具 |
| ⚱ | 圣物龛（商店） | 遗物、买命 |
| ⛺ | 集市（Boss 后） | 三家店合在一条街上 |
| ？ | 事件（短路线上） | 乌鸦赌局 / 无主坟 / 流浪骨匠 / 骨灰祭坛：不打仗、有取舍，不涨王国警戒、不打断连战 |
| ☠ | Boss | 章末首领战，灵魂 ×3.5 |
| 👑 | 白冠王都 | 终章：三波连打，通关 |

### 3.3 「打 1–3 波就去升级，打得多后面升级多」
每章两段，每段有 **短 / 中 / 长** 三条路线（1 / 2 / 3 场战斗）汇合到商店：
- 敌人强度 = **地图深度**（越往右越强）+ **王国警戒**（你比标准多打了几场，人类就更警觉；少打了几场就稍弱，见 11.3）+ **连战压力**（不进店连打第 2 场 +10%、第 3 场起 +20%）。
- **连战加成**：连续打第 2 场战斗起灵魂 +30%、第 3 场起 +60%；连战 ≥ 2 场后进店：多 1 件商品 + 第一次刷新免费；≥ 3 场：多 2 件商品 + 全店八折。
- 所以：短路线 = 稳、升级少；长路线 = 中途不能升级、敌人越来越强（压力大），但到下一个商店时买得最多。模拟结果三种走法都能通关（短 59% / 随机 76% / 长 66%），没有唯一正解。

### 3.4 生命
- 3 条命。普通战 / 要塞战败：-1 命，拿已击杀部分的骨头、没有灵魂和遗物，**节点算通过**（继续往前走）。
- Boss / 王都战败：-1 命，**原地重打**（骨头按已击杀部分结算后给你重新拉杆）。
- 0 命 = 本局结束（结算界面 → 重新开始）。圣物龛 / 集市可以花灵魂买回 1 条命。

### 3.5 三章 + 终章
| 章 | 地貌 | 敌人梯度 | Boss |
|---|---|---|---|
| 第一章 · 麦田乡野 | 麦田、风车、河边哨岗、石桥 | 民兵 → 轻步兵 | **千垒督军**（石桥镇） |
| 第二章 · 狮鹫高地 | 伐木营、哨塔、修道院、猎场、采石场 | 步兵 → 精锐 | **破阵王·铁冠 + 王廷近卫**（狮鹫堡） |
| 第三章 · 白塔圣域 | 朝圣营、钟楼、圣泉、教堂、审判所 | 精锐 → 重装 | **圆桌骑士团（6 人）**（白塔） |

## 4. 经济：双货币 + 锚点

### 4.1 两种货币的分工
| | 骨头（人类的肉身腐烂后留下的） | 灵魂（人类的魂） |
|---|---|---|
| 作用 | **只用于拉杆**（每战的军队） | **只用于商店**（老虎机、兵种、符号、道具、遗物） |
| 来源 | 战利品（击杀）+ 残部奖励（存活率）+ 老虎机奖金 | 节点结算（固定额 × 连战加成） |
| 时间尺度 | 一场战斗 | 一整局 |
| 是否结转 | 结转（花不完留到下一战） | 结转 |

### 4.2 骨头锚点：每战拉杆次数
- 拉杆价格 1、2、4、8…翻倍，每战重置（保留）。所以**拉杆次数 = log₂(骨头 + 1)**：骨头翻倍只多拉 1 次，天然防止「后期骨头太多拉几十次」。
- 锚点（目标拉杆次数，平均路线）：

| 阶段 | 教学 | 第一章 | 第二章 | 第三章 | 终章 |
|---|---|---|---|---|---|
| 每战拉杆 | 3–4 次 | 4 → 6 | 6 → 7 | 7 → 9 | 9 → 11 |
| 需要骨头 | 15 | 15 → 63 | 63 → 127 | 127 → 511 | 511 → 2047 |

- 因此**战利品额度按节点深度指数增长**（每个节点约 ×1.25），每个敌人掉的骨头 = 该节点额度 × 它的战力占比；战败时按已击杀的战力比例拿。
- 残部奖励 = 战利品 × 50% × 存活率（打得漂亮全程都有同样比例的回报）。
- 安全阀：每战最多拉杆 15 次（正常玩不会碰到，防止奖金无限循环）。

### 4.3 灵魂锚点：每次进店能买 1–3 件
- **1 场普通战 = 10 灵魂**（定义为 1 个「战斗单位」），全局不通胀（学杀戮尖塔：收入不随层数涨，价格也不涨）。

| 来源 | 灵魂 |
|---|---|
| 教学战 | 20（刚好够第一家店买一件大件） |
| 普通战 | 10（连战第 2 场 13，第 3 场 16） |
| 要塞 | 20 |
| Boss | 35 |
| 遗物三选一点「跳过」 | +5 |

| 商品 | 价格（灵魂） | 约等于 |
|---|---|---|
| 新兵种（+1 列滚轴、+1 万能） | 22 / 32（第 4 / 5 种） | 2–3 战 |
| 老虎机扩行（3 行 → 4 行） | 40 | 4 战 |
| 万能符号 +1 | 16 | 1.6 战 |
| 符号 +2（某个兵种） | 8 | 0.8 战 |
| 迁坟（某兵种 -1 符号） | 6，之后每次 +4 | 0.6 战 |
| 阵型升级（某阵型倍率 +1） | 12 | 1.2 战 |
| 老虎机道具 | 6–10 | 0.6–1 战 |
| 遗物（专属 / 共用 / 核心） | 24 / 20 / 30 | 2–3 战 |
| 买命 +1 | 30 | 3 战 |
| 刷新货架 | 3，同店每次 +2 | |

- 价格 ±8% 随机浮动；每家店随机一件**半价特价**。
- 一局平均灵魂收入约 300，想买的东西总价约 380 → 永远买不全，必须取舍。

## 5. 商店

### 5.1 三家店 + 集市
| 店 | 店主 | 货架 | 刷新物件 |
|---|---|---|---|
| 墓园 | 掘墓人 | 3 口棺材（新兵种，至少 1 个和现有兵种能组成玩法）+ 2 份符号 + 迁坟 | 摇守墓铃 |
| 骨匠工坊 | 骨匠 | 扩行 / 万能符号 / 阵型图纸 ×1–2 / 老虎机道具 ×2 | 拉下传送带闸 |
| 圣物龛 | 守龛人 | 遗物 ×3（只出你已有兵种 + 共用）+ 买命 | 点一支新蜡烛 |
| 集市 | 三位店主 | 三家店各取一部分，一条街摆开 | 各摊自己刷新 |

### 5.2 货架生成算法（保证成长曲线有效）
1. **相关性**：只出和当前构筑有关的东西——遗物只出已有兵种的专属 + 共用；符号只出已有兵种；新兵种至少 1 个能和现有兵种组成 8 条组合玩法之一。
2. **保底槽**：每家店第一格固定是「结构成长」（墓园 = 新兵种；工坊 = 扩行或万能；圣物龛 = 一件核心遗物），刷新不会把保底槽刷成别的类别。
3. **买得起保底**：货架上至少 1 件价格 ≤ 当前灵魂（灵魂 ≥ 6 时）。
4. **权重**：遗物按兵种在符号池里的占比加权（主力兵种的遗物更容易出）；没见过的核心遗物每次没出现，下次权重 +50%（坏运气保护）。
5. **不重复**：同一次进店不重复；本局已经买过的不再出现。
6. **连战奖励**：按 3.3 增加货架数量和折扣。

### 5.3 交互：「东西都在场景里」
**一句话：看 = 鼠标移到商品上（以后是走近）；买 = 按住它 0.5 秒（以后是按住交互键）。**

- 场景：横版房间（以后是 3D 房间 + 2D 贴图）。货架是地上的台座 / 棺材 / 祭坛，商品摆在上面轻微浮动发光。
- **价签在商品下方**：灵魂图标 + 价格；买不起 = 红字；特价 = 红色缎带 + 删除线原价；买完原地变「售罄」木牌。
- **聚焦**：鼠标悬停（或角色走到附近）→ 商品抬起，上方弹出说明框（名字、类别、效果、对当前构筑的具体影响，例如「老虎机 4×3 → 4×4」），框底写「按住购买」。
- **购买**：在商品上按住鼠标（或按住 E）→ 价签外圈进度环 0.5 秒填满 → 成交：灵魂从顶栏飞向店主、商品飞向我方角色，店主说一句台词，原地变售罄。中途松开 = 取消。按住本身就是确认，不弹窗。
- **买不起**：按住时进度环变红不涨，价签抖动，店主说「还差 X 灵魂」。
- **角色**：亡灵领主在房间里走动（点地面 = 走过去，WASD 也能走）。点商品时角色会走过去，表现「是我走过去买的」，为以后的 3D 版本留好接口。
- **刷新 / 离开**都是物件：摇铃、拉闸、点蜡烛；离开是右边的门。身上还有能买得起的东西时，第一次点门店主会提醒，再点一次才走。
- **教会玩家怎么买**：第一次进店，店主开场白直接说「看中什么，按住它就归你」。

### 5.4 以后做 3D 时
| 2D 原型 | 3D 版本 |
|---|---|
| 鼠标悬停 | 角色朝向 + 距离 < 1.5 米的最近商品自动聚焦 |
| 说明框贴在商品上方 | 面向镜头的世界空间面板（Billboard），随商品高度偏移 |
| 价签 | 商品下方的实体木牌 / 墓碑铭牌，数字用贴图字体 |
| 按住鼠标 | 按住交互键（手柄 X / 键盘 E），进度环画在价签上 |
| 门 / 铃 / 闸 / 蜡烛 | 同样的物件，交互提示一致 |

## 6. 结算与奖励
每个战斗节点打完弹「战斗结算」：
- **骨头**：战利品 +X（击败 N 名人类）、残部 +Y（存活 a/b）→ 合计，下一战能拉几次。
- **灵魂**：节点奖励 +A、连战加成 +B → 合计。
- 然后 **遗物三选一**（只出已有兵种 + 共用；要塞保证一件核心遗物；可跳过换 5 灵魂）。
- 然后回到地图，军旗停在这个节点上。

## 7. 难度与敌人

### 7.1 方法：预算 + 数量（行业惯用的「威胁预算」）
- 每个战斗节点有一个**战力预算**：预算 = PAR(有效深度) × 心流系数 F × 节点系数 bm × 连战压力 × 难度档（轻松 0.8 / 标准 1 / 困难 1.2）。
  PAR(d) = 876 × 1.095^d 是自动模拟测出的「中等玩家 50% 胜率线」；有效深度 = 地图深度 + 王国警戒修正。
- 每个节点有一个手工编排的**敌人主题**（2–4 种，65 种敌人按章节分档：第一章民兵 / 轻步兵，第二章步兵 / 精锐，第三章精锐 / 重装），按 50% / 30% / 20% 分配预算，人数 = 预算份额 ÷ 该兵种单兵战力。
- 不改敌人的基础数值：**难度主要靠人数和兵种档次**（用户建议，也最可控）。上限每战约 70 名敌人（性能 + 可读性）。
- 校准：用自动模拟测「平均策略玩家」在每个节点的战力，再把预算倍率调到第 2.2 节的压力比目标，用胜率复核。

## 10. 自动测试与调参方法
- 页面内置无界面模拟器：拉杆（同一套阵型 / 消除 / 幸运规则，没有动画）+ 战斗（同一个战斗引擎直接步进）+ 商店（同一个货架算法）。
- 三种「机器人玩家」：**均衡**（优先扩充老虎机 → 主力兵种符号 → 核心遗物）、**贪心**（只买最贵的）、**随机**（随便买、随便走）；路线分短 / 长 / 随机。
- 每种组合跑多局，记录每个节点：压力比、胜率、拉杆次数、骨头 / 灵魂、军队人数、战斗时长、购买件数。

## 11. 校准结果（2026-10-11 夜间，自动模拟）

### 11.1 方法
1. **先定经济，再定难度**：灵魂价格表 → 骨头额度 → 敌人预算 → 首领倍率，一次只动一个变量。
2. **找 50% 胜率线（PAR）**：每场正式战斗前，用同一支军队、敌人预算乘 0.7 / 1 / 1.4 / 2（第一轮 1–6.5）各打一次，插值出胜率 50% 的预算倍率 m50。
   普通战的「50% 胜率战力」拟合为 **PAR(d) = 876 × 1.095^d**（d = 地图深度，18 个节点回归），这条线就是「中等玩家在这个深度能打多强」的锚点。
   （v2.3 加了「起步慢组合的开局赠礼」后整体变强，基准同比上调 5%：PAR0 = 920。）
   同样预算下，要塞 / 首领 / 王都比普通战难（m50 只有普通战的 0.75–0.88 倍：兵力集中、机制更狠），所以它们的心流系数单独折算。
3. **心流系数 F**：本节点敌方战力 = PAR(深度) × F。
4. **按路线复核**：「总走最短路线」「随机」「总走最长路线」三种机器人分别跑 64–80 局，看通关率和时长。

### 11.4 经济实测（随机路线，80 局）
- 每战拉杆次数：第一章 4–6 次（中位 5），第二章 6–8 次（中位 7），第三章 8–11 次（中位 10）；全程最高 13 次，99% 分位 12 次（安全阀 15 次从未触发）。

- 160 人对 70 人的大战，战斗步进约 0.2 毫秒 / 帧，性能没问题。
- 黎明鏖战：80 秒后双方每 5 秒按最大生命流血（3%、6%、9%…），防止极少数首领战僵持（模拟里约 0.2% 的战斗超过 150 秒）。

### 11.5 已知偏差 / 待人工验证
- 机器人不会用老虎机道具、不会调整列顺序、遗物只按「核心 > 主力兵种」挑；真人通常更强。真人试玩如果觉得偏简单，标题页可以选「困难」（敌方战力 ×1.2），偏难就选「轻松」（×0.8）。
- 开局组合强弱有差（随机路线下：移动雷电 13/14、临时生命 11/13；号令积咒 2/4、治疗转伤害 7/12），后续可以按组合微调核心遗物。
- 「胜利时存活率」普遍偏高：大规模混战是兰彻斯特平方律，强的一方会碾压，弱的一方会崩，很难打出「险胜」。想要更多险胜，需要在战斗里加「翻盘」机制（例如人类残兵溃逃、亡灵残血狂暴）。

## 12. v3.0 改动（2026-10-11 下午）

依据：《分析报告_地图_老虎机运气_事件.md》（根因分析），以及学习杀戮尖塔后定下的地图方案（`地图方案预览_杀戮尖塔式.html`）。本节取代第 3 节「地图」中的固定地图、连战、王国警戒部分。

### 12.1 地图（杀戮尖塔式，每局随机）
- **网格**：每章 5 条车道 × 7 层 + 首领，生成 5 条路径；每一步只能走到相邻车道，生成时禁止交叉（左右邻居的边界夹住新边）。
- **固定层（每条路都会经过）**：
  - 第 1 层：普通战（easy 池）；
  - 第 4 层：集市（墓园 / 骨匠工坊 / 圣物龛，每家 2 件）；
  - 第 7 层：篝火；
  - 首领之后：大集市（9 件）。
- **随机层（2、3、5、6）**：精英 22%、未知 25%、篝火 5%（只在 3、5 层），其余普通战。
- **规则**：
  - 第一章第 2 层没有精英；精英 / 篝火不连着；同一岔口的子节点类型不同；
  - 每张图都要同时有「2 个精英」的险路和「0 个精英」的稳路，否则重新生成。
- **未知节点**：进入时才揭晓——乌鸦赌场 35 / 事件 30 / 宝箱 15 / 埋伏 20。没出现的类型下次权重 +50%，同杀戮尖塔的「？」房间。
- **深度**：只按横向位置算（敌人强度、骨头额度和走哪条路无关）。路线等长，所以每条路的战斗场数、遗物三选一次数一样，差别只在节点难度和奖励。

### 12.2 经济（奖励按风险发）

### 12.3 老虎机（运气）
- **平时完全走概率**：出阵率 55%（第一章）/ 60% / 67%。
- **幸运灯**：连续落空点亮一盏，出阵清零。3 盏全亮 → 下一转「大奖转」：
  - 盘面里一定放一个 ×6 起的大阵，权重 1/倍率（越大越少见），其余格子照常随机；
  - 配合慢停、金色拉杆、横幅演出。
- **万能**：不再随扩盘白送，工坊 30 灵魂，最多 1 张。每多 1 张，5×4 盘面出阵率 +15 个百分点。成长改靠阵型图纸（10 灵魂、篝火免费）提高倍率。
- **实测**：
  - 一半以上的战斗出现连续落空（v2.3 只有 1–18%）；
  - 大奖转每 20 / 20 / 40 转一次；
  - 大奖转一次出 11.5–18 名兵（普通一转 1.6–4.0）。

### 12.4 乌鸦赌场（12 格轮盘）
- **格子**：空 6、×2 3、×4 2、×6 1。期望 ×1.67：X0 占一半、其余至少 ×2 时期望必然 ≥ 1，所以对玩家有利，事件不至于成了陷阱。
- **下注**：筹码押全部骨头的 1% / 5% / 10%，最多转 3 次（3 枚头骨代币）。
- **交互**：在筹码上按住 0.5 秒下注，和商店一致。球逆着轮盘转、减速、弹跳后落进格子；输了显示「Nope!」。
- **影响**：拉杆价格翻倍，所以骨头是对数价值。押 10% 时，3 次全中 ×6 也只多约 1.75 次拉杆。赌场是调剂，不是转折。

### 13.2 规则

- **盘面**：
  - 开局 3×3，最终 5×4，一共升 3 次（+2 列、+1 行），顺序由玩家选。
  - 价格 30 / 45 / 60 灵魂（第 1 / 2 / 3 次）。
  - **列数不能超过兵种数**：横着扩盘要先在墓园招兵。
  - 兵种和列数不再一一对应：招兵只往老虎机里加 4 张该兵种的符号。
- **刷新**：
  - 每家店各自刷新，底价 4 / 5 / 3，每刷一次翻倍，每次进店重置。
  - 刷新把这一家的商品全部换新，买走的也补上。
- **输了时间倒流**：
  - 扣 1 命，回到这一战开始拉老虎机之前（存档点 `state.snap`：骨头、幸运灯、老虎机道具、战斗道具），随机数不还原。
  - 首领、王都每一波都一样，不能跳过，命用完就输。
- **命**：开局 3 条，最多 5 条，只有篝火能回。
- **骨头**：
  - 每战目标拉杆次数 T(d) = 5 + 5.5 × (d/32)^1.1（第一章 5–6 次，王都约 10 次）。
  - 教学战战利品 31。
  - 每战开始至少 15 骨头（`MIN_BONES`，能拉 4 次，保证连空 3 次后有大奖转）。
- **空列不补兵**（删掉 `state.minOne`）。
- **老虎机道具**（14 种，只在老虎机静止时用）：
  - 拉杆前用：半价券、锁价齿轮、空转保险、点名赌约、连锁悬赏、定轴钉、定向砝码。
  - 作用于残盘：黄金格、剔骨针、微调摇把、换位钩、单列重转。
  - 立刻生效：幸运灯芯、招魂幡。

### 13.3 校准（中等策略机器人，各 200 局）

- **难度系数**：
  - FLOW_BATTLE [[.26, .38], [.31, .34], [.31, .35]]
  - FLOW_ELITE [.50, .52, .41]
  - FLOW_BOSS [.55, .48, .55]
  - FLOW_FINAL [.61, .62, .36]
- **方法**：每场战斗额外试打 0.6–3.1 倍敌军，插值出各节点在目标胜率下的倍率（普通战 94%、精英 80%、首领 75%、王都 85 / 80 / 75%），再用路线平衡微调。
- **机器人打法**：
  - 买东西顺序：扩盘 > 兵种（盘面每种兵至少 3 格才招）> 主力兵种符号 > 道具。
  - 老虎机道具：拉杆前用砝码、保险、半价、锁价、悬赏、灯芯；空盘后先试微调 / 换位能不能确定成阵，再用重转 / 剔骨针；开战前用招魂幡补空列。
  - 战斗道具：留给精英、首领、王都，朝最密集的位置扔。
- **结果**：见《版本说明与验收清单》第 0.2 节。随机选路 57%、冒险 52%、稳路 56%、新手 15%、只用 3 种兵 100%。

### 13.4 已知问题

- **只用 3 种兵压倒性最优**：
  - 现象：同盘面下，兵种越少，同种符号越容易连成大阵，概率按格数成指数涨。
  - 数据：4×4 盘面，3 种兵每转 4.4 名，5 种兵 1.0 名。
  - 修法候选见验收清单 0.4：赔率按稀有度 / 编制加成 / 限制占比 / 新兵种 2 张符号。
- **新手乱买很难通关**：主要原因是没买盘面升级。
- **机器人的盲区**：它不会用定轴钉、点名赌约、黄金格，也不会调列顺序，真人会更强。
