# 亡灵老虎机 · 道具设计

版本：v0.2 · 2026-10-10

本稿收录七种老虎机道具：半价券、锁价齿轮、空转保险、点名赌约、连锁悬赏、黄金格、剔骨针。目标是让玩家通过降低投入、押中奖条件和操作残盘，在费用不断翻倍的情况下争取继续拉杆，同时权衡保留兵力与回收士兵。

七种道具的收录范围、“仅在完全静止时使用”的时序，以及货币奖励应按拉杆费用的比例成长，已由用户确定。下文把使用方式、结算口径和组合规则补全为首版机制；采用优惠前费用作为中奖基数、具体奖励比例及其他限制属于本稿建议，尚未经试玩平衡。

本版将货币奖励统一写成百分比。文中 8、16、48 等整数只用于举例，实际金额随生成该盘的拉杆费用计算，不是固定奖金。

## 1. 所有道具共用的规则

### 1.1 使用时机：只在老虎机完全静止时操作

“静止”必须同时满足：滚轴已停、阵型奖励已结算、消除与下落已完成、没有可继续自动结算的阵型。滚轴刚停但还没结算，不属于可操作时机。

两条合法流程：

~~~text
静止 → 成功付费拉杆 → 转动 → 阵型结算 → 消除 → 下落补新
                                    ↑                 ↓
                                    └── 有新阵型 ─────┘
                               无新阵型且动画结束 → 静止

静止 → 使用剔骨针 → 移除目标 → 下落补新 → 检查阵型
                                             ↓
                                 有阵型：完整自动结算循环
                                 无阵型：回到静止
~~~

- 从拉杆启动到整串连锁结束，不接受任何道具使用、选目标或更改已生效赌约的操作。
- 剔骨针启动后的移除、下落和连锁，也属于同样不可插入操作的过程。
- 结算期间点击道具不生效，也不排队留到结算结束后执行。
- 奖励自动发放，连锁之间没有“领取”“继续”或选择道具的窗口。
- 完整结算后，玩家可再使用一个道具；如果它又形成阵型，就再自动结算到底。
- 骨头不足不禁止使用当前残盘道具；获得骨头也不会自动拉动下一次拉杆。

### 1.2 “一盘”与“一次连锁”分别是什么

| 名称 | 定义 | 结束条件 |
|---|---|---|
| 一盘 | 一次成功付费拉杆产生的盘面，以及此后在它上面发生的全部道具操作、消除与补新 | 下一次成功拉杆开始，或玩家结束本次招募、进入战斗 |
| 一次自动结算 | 一次拉杆或一次剔骨针引起的连续结算过程 | 没有可结算阵型，且相关动画全部完成 |
| 一轮消除 | 在同一份盘面上判定一批阵型、发奖并消除，然后统一下落补新 | 下落补新完成 |
| 当前残盘 | 一次自动结算完整结束后留下的静止盘面 | 继续改盘或开始下一次拉杆 |

一轮消除可以同时结算多个阵型，但连锁计数只增加 1。同一次自动结算中，下落后再次形成阵型，才进入下一轮消除。

几次被静止期隔开的剔骨针操作，属于几次独立自动结算，不能把它们各自的一轮消除相加，算成三连消。

收起、重新打开老虎机面板不会结束当前这一盘。没有成功扣费的拉杆尝试也不会结束当前盘面。

### 1.3 金额：报价、实付和奖金基数分开计算

| 符号 | 含义 | 用途 |
|---|---|---|
| C | 下一次拉杆的未打折报价 | 默认依次为 1、2、4、8……，锁价齿轮可以阻止某一次上涨 |
| B | 生成当前这一盘时的基础费用，即优惠前报价 | 本盘所有中奖类骨头奖励的计算基数 |
| P | 生成当前这一盘时实际支付的骨头 | 空转保险的退款基数 |

成功拉杆时，先确定 B = 当次 C，再算折扣后的 P。支付完成后，下一次报价通常变为 2B；使用锁价齿轮则保持 B。

- 半价券改变 P，不改变 B。
- 中奖金额 = 向下取整（B × 奖励比例）；退款金额 = 向下取整（P × 退款比例）。两者不要混用基数。
- 奖金与退款均为额外获得的骨头，不直接修改下一次报价。
- 当前残盘上的道具结算沿用本盘 B，不重新付拉杆费、不推进价格档位、不另算一次付费拉杆。
- 使用道具本身不额外收费，代价是消耗道具数量。
- 骨头为整数。半价付款向上取整且最低为 1；保险退款向下取整。

例：标价 8，使用半价券后实付 4；这一盘 B = 8、P = 4。普通横排五连奖 16，黄金格奖 8，空转保险最多退 2。下一次报价是 16；若同时使用锁价齿轮，则是 8。

### 1.4 奖金比例与后续拉杆的购买力

设计原则：**中奖按本次优惠前费用的比例计算；退款按本次实际支付的比例计算。**

| 可选基数 | 对道具组合的影响 | 本稿用途 |
|---|---|---|
| 本盘优惠前费用 B | 奖励随拉杆费用成长，半价和锁价不会顺带削减奖金 | 中奖奖金 |
| 本盘实付 P | 用于奖金会使半价券同时把奖金减半；用于退款则准确对应玩家实际损失 | 空转保险 |
| 下一次拉杆费用 C | 用于当前奖金会使锁价齿轮压低奖金；之后的报价调整还可能影响旧盘奖励 | 展示继续拉杆的门槛，不作为当前盘面奖金基数 |

拉杆成功启动时就固定 B。本盘后续的自然连锁、剔骨针和黄金格始终沿用它。为下一次拉杆准备半价券、下次报价已经上涨，或玩家骨头余额发生变化，都不能改写旧盘 B。

所有奖励比例都表示本次实际入账的骨头，不另外自动退回拉杆费。例如无折扣支付 8 后，五连奖励 200% × 8 = 16；余额从 0 变为 16，不是再退 8、合计入账 24。明示的保险退款单独依其规则处理。

以下按正常翻倍、后续没有折扣或锁价、暂不计算原有余额与新的中奖收入解释奖金购买力：

| 奖励 | 正式比例 | 获奖后能支付什么 |
|---|---|---|
| 基础横排五连 | 每行 B 的 200% | 下一次正常拉杆的全部费用 2B |
| 点名赌约命中 | 每行 B 的 600% | 接下来两次正常拉杆的费用之和：2B + 4B |
| 连锁悬赏 | B 的 300% | 支付下一次的 2B 后，还余 B |
| 黄金格 | B 的 100% | 下一次正常拉杆费用的一半 |
| 空转保险 | 实付 P 的 50%，向下取整 | 补回本次实际损失的一部分，不保证够下一次拉杆 |

这里不能把“奖金除以下一次费用”直接叫作可拉杆次数，因为后续费用还会翻倍。奖金 6B 可以支付两次正常拉杆，不是三次；连续三次需要 2B + 4B + 8B = 14B。

不同阶段使用完全相同的比例：

| 本盘基础费用 B | 下一次正常费用 | 五连 200% | 点名命中 600% | 三连悬赏 300% | 黄金格 100% |
|---|---|---|---|---|---|
| 8 | 16 | 16 | 48 | 24 | 8 |
| 64 | 128 | 128 | 384 | 192 | 64 |
| 512 | 1024 | 1024 | 3072 | 1536 | 512 |

半价券减少支出但保留上述奖金，锁价齿轮降低下一次门槛但保留上述奖金，这是两种道具应有的组合收益。比如 B = 64，半价实付 32，五连仍奖 128；再叠加锁价，下一次只需 64。是否使用这些消耗品由玩家决定，不把减价同步变成减奖。

说明文字展示比例，同时显示算好的骨头数，例如“横排五连：本盘基础费用的 200%（128 骨头）”。当前盘面按固定 B 展示；为下一次拉杆准备的效果按下一次优惠前报价预览，并明确标注“下次拉杆”。

士兵产出仍由阵型决定，不随 B 成比例增加。票价变大不会把五连的 4 张剑士卡变成几十或几百张。

### 1.5 基础横排骨头奖

点名赌约需要一个可替换的基础奖金规则，本稿配套采用：

**横向一整行五个相同兵种符号形成有效五连并被阵型消除时，额外获得本盘基础费用 B 的 200%，即 2B 骨头。士兵奖励照常结算。**

- 这是基础奖励规则，不是第八种道具。
- 五列四行的盘面只有横向五连符合本条；竖向四连不算横排五连。
- 每轮消除前检查横排；该行五格必须都进入这一轮阵型的实际消除范围，才发放横排骨头奖。
- 更大的阵型包含完整横排五连时，该行仍能领奖。例如同兵种的 5×2 阵包含两行五连，基础骨头奖合计 4B。
- 每行在同一轮消除中只领一次横排奖，不能因为它同时包含三连、四连而重复领取。
- 同一轮有多行合格五连，各行分别领奖；后续补入的新符号再次形成五连，可以再次领奖。
- 士兵产出沿用现有阵型的优先级和数量规则，不因为附加骨头奖重复发兵。
- 若启用万能符号，它可以补足已有明确兵种的五连；该行至少有一个真实兵种符号，其余必须为同兵种或万能符号。全万能的一行不属于本稿横排奖的合格五连，避免无兵种归属的赌约判定。

### 1.6 两种使用方式与消耗时点

| 方式 | 道具 | 操作与消耗 |
|---|---|---|
| 为下一次拉杆准备 | 半价券、锁价齿轮、空转保险、点名赌约、连锁悬赏 | 静止时加入“下次拉杆”栏，成功付费启动时正式消耗 |
| 立即作用于当前残盘 | 黄金格、剔骨针 | 静止时选中道具，再点击目标格；目标有效、效果实际执行时正式消耗 |

准备类道具可以在拉杆前取消；点名赌约也可以在拉杆前更改目标。准备期间只预留库存，取消后释放。钱不够、尚未启动的拉杆尝试不会消耗道具。

同一种准备类道具，每次拉杆最多准备一份；不同种类可以一起准备。重复点击已准备道具用于取消，不继续叠加数量。

在当前残盘上准备的新道具，仅属于下一次拉杆。随后使用剔骨针，不会触发、消耗或提前激活这些准备中的道具。

当前这一盘已经生效的赌约、悬赏，可以与为下一次拉杆准备的道具同时存在；界面必须分别标注“本盘生效”和“下次拉杆”。

目标型道具在点击目标前可以取消。点击目标并执行后不能撤销，不能回退已揭晓的新符号。当前没有真实付费产生的盘面时，黄金格与剔骨针不可使用；演示盘面不产奖励。

玩家结束招募进入战斗时，尚未消耗的准备道具退回库存；已生效的本盘效果结束，已消耗道具不返还。

## 2. 半价券

**用途：降低下一次拉杆的立即支出。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 下一次成功付费拉杆 |
| 操作 | 静止时点击半价券，加入“下次拉杆”栏；界面立即更新实付预览 |
| 效果 | P = max(1, ceil(C × 50%)) |
| 消耗时点 | 下一次拉杆成功启动时消耗 1 张 |
| 结束时点 | 完成本次付款后效果结束 |
| 叠加 | 同次最多 1 张；可以与其余准备类道具组合 |

使用后，如果打折价已经付得起，拉杆按钮即可变为可用；无需先凑齐未打折报价。

半价不降低价格档位，也不降低本盘奖金基数。报价 8 时付 4，正常情况下下一次仍报 16。

报价为 1 时使用没有收益，半价券不可准备，显示“当前已是最低费用”。

**界面文案：**“下一次拉杆费用减少 50%，最低支付 1 骨头。中奖奖金按优惠前费用计算。”

**示例：**持有 5 骨头，报价 8。准备半价券后显示“原价 8／实付 4／之后报价 16”。拉杆后剩 1 骨头，本盘 B 仍为 8。

## 3. 锁价齿轮

**用途：取消下一次拉杆带来的一次涨价，保留后续继续拉杆的机会。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 下一次成功付费拉杆后的报价更新 |
| 操作 | 静止时点击锁价齿轮，加入“下次拉杆”栏 |
| 效果 | 本次拉杆后，下一次 C 保持为本次 B，不变成 2B |
| 消耗时点 | 下一次拉杆成功启动时消耗 1 个 |
| 结束时点 | 阻止本次报价上涨后结束 |
| 叠加 | 同次最多 1 个，不能用两个齿轮把价格倒退 |

齿轮不降低本次实付，不撤回已经发生的涨价。当前报价 16 时准备齿轮，本次仍从 16 计算付款，不能退回 8。

它也不让下一次拉杆免费。正常序列 8 → 16 → 32，使用一次后变为 8 → 8 → 16；后续从保留的档位继续上涨，不补收这次被取消的涨价。

**界面文案：**“下一次拉杆后，费用不翻倍。”

**示例：**报价 8，同时准备半价券与锁价齿轮，实付 4，之后报价 8。本盘 B = 8；半价券已经用掉，若下一次不用新的半价券，就需要支付 8。

## 4. 空转保险

**用途：为下一次付费拉杆的完全落空提供部分退款。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 下一次付费拉杆直接引起的那一次完整自动结算 |
| 操作 | 静止时点击空转保险；“下次拉杆”栏展示本次最多退还多少骨头 |
| 触发条件 | 从拉杆到首次完全静止，实际形成的有效阵型总数为 0 |
| 退款 | floor(P × 50%)，按实际支付计算 |
| 消耗时点 | 拉杆成功启动时消耗 1 份，不论最终是否退款 |
| 结束时点 | 这次付费拉杆的完整自动结算结束；符合条件就退款一次，然后保险结束 |

有阵型就不算空转，即使没有获得骨头奖金、点名赌约押错兵种，或得到的士兵很少，也不触发保险。

退款不撤回价格上涨。如果未使用锁价齿轮，报价 8 的空转即便退了 4，下一次仍要 16。

保险只负责付费拉杆，之后使用剔骨针引起的零阵型结算不会再退款。已经赔付后，玩家用剔骨针救出阵型，可以正常获得新奖励，也不会被收回此前保险赔付。

**无收益处理：**实付只有 1 骨头时，向下取整的退款为 0，保险不可准备。若先准备保险，再用半价券使实付降为 1，则自动取消保险准备、释放库存，并显示“本次退款为 0，保险已退回”；其他准备道具保留。

**界面文案：**“下一次拉杆完全没有阵型，返还实付骨头的 50%，向下取整。”

**示例：**报价 8，半价后付 4。整次没有阵型，保险退 2；若出现任何一个三连阵，保险退 0。两种情况下保险都已消耗。

## 5. 点名赌约

**用途：放弃其他兵种的横排骨头奖，追求指定兵种的更大回报。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 下一次拉杆产生的整盘，包括此后的残盘道具结算 |
| 操作 | 静止时点击赌约，选择一个兵种，加入“下次拉杆”栏 |
| 可选目标 | 当前符号池中有数量的兵种符号；万能符号不能作为指定兵种 |
| 指定兵种五连 | 每行奖励本盘基础费用的 600%，即 6B；替换基础的 200%，不相加 |
| 其他兵种五连 | 该行横排骨头奖变为 0；士兵产出与消除照常 |
| 消耗时点 | 下一次拉杆成功启动时消耗 1 份 |
| 结束时点 | 本盘结束；不会在首次中奖后提前结束 |

选择的是兵种，不是行、列或单个格子。可以在启动拉杆前更改目标；启动后，该盘目标锁定，即使老虎机后来静止，也不能更改。

本盘每个符合条件的指定兵种横排都能领奖。靠剔骨针在残盘上补出的指定五连，同样获得 6B；无需再付拉杆费。

“其他兵种不发奖”只影响横排骨头奖。黄金格、连锁悬赏、符合条件的保险退款，以及回收士兵得到的骨头不受影响。赌约不改变符号出现概率。

点名赌约必须在生成这盘的拉杆前准备。看见当前残盘后再准备一张，只对下一次拉杆生效，不能追认当前已经出现或即将由剔骨针补出的五连。

**界面文案：**“押一个兵种。本盘该兵种横排五连奖基础费用的 600%，其余横排不发骨头奖。士兵照常获得。”

**示例：**本盘 B = 8，押剑士。剑士横排五连奖 48 骨头，不再另加基础 16；弓手横排五连奖 0 骨头，但照常召唤弓手。如果同轮有两行剑士五连，横排奖合计 96。

## 6. 连锁悬赏

**用途：奖励一次完整结算中持续发生的三轮连消，让下落过程保留悬念。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 下一次拉杆产生的整盘内的各次自动结算 |
| 操作 | 静止时点击悬赏，加入“下次拉杆”栏 |
| 触发条件 | 任意一次自动结算连续达到 3 轮消除 |
| 奖励 | 本盘基础费用的 300%，即 3B 骨头 |
| 消耗时点 | 下一次拉杆成功启动时消耗 1 份 |
| 领奖次数 | 本盘最多 1 次；超过三轮不继续加发 |
| 结束时点 | 领奖后完成，或本盘结束时失效 |

连锁按“消除后下落，再成阵”计数：

~~~text
第一批阵型消除：第 1 轮
下落又形成阵型并消除：第 2 轮
再次下落成阵并消除：第 3 轮 → 自动获得悬赏
~~~

同一轮出现三个独立阵型，只算一轮。剔骨针直接移除一格以及它引起的首次下落，都不算消除轮数；下落后真正形成阵型并消除，才算第 1 轮。

如果付费拉杆只连消两轮，悬赏仍在本盘有效。之后一次剔骨针引起了三轮连消，可以领奖。若剔骨针也只有一轮，不能把之前两轮加上这一轮领奖。

悬赏支付后，即使本盘另一次剔骨针又连消三轮，也不再支付。另一份新准备的悬赏只能等下一次付费拉杆生效。

**界面表现：**自动结算中显示“连消 1/3、2/3、3/3”；未完成就停下时，保留“本盘悬赏未完成”，下一次结算重新从 0 计数。领奖后显示“本盘已领取”。

**界面文案：**“本盘任意一次连续消除达到 3 轮，获得基础费用的 300%。每盘一次。”

**示例：**B = 8，第三轮消除判定成立时自动奖励 24 骨头。后面继续消除第四、第五轮，照常获得阵型奖励，悬赏不重复发放。

## 7. 黄金格

**用途：给当前残盘上的一个位置增加赏金，让玩家围绕它规划一次消除。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 当前静止残盘的一个格子 |
| 操作 | 点击黄金格道具，盘面进入选格状态；点击有效格子即放置标记 |
| 消耗时点 | 标记成功放置时立即消耗 1 份 |
| 触发条件 | 被标记的格子首次参与有效阵型的消除 |
| 奖励 | 本盘基础费用的 100%，即 B 骨头，额外叠加在正常奖励上 |
| 有效期 | 领奖前持续存在；下一次成功拉杆或本次招募结束时失效 |
| 数量限制 | 同时最多有 1 个未领取的黄金格；领取后可再消耗一份重新标记 |

黄金标记附着在固定的行列位置，不附着在符号上。符号下落、更换后，标记仍停在原格。

放置标记不移动符号、不生成新符号，也不自动发奖；它不能给此前已经消除的阵型补发奖励。添加标记后，老虎机仍处于静止，玩家可以继续使用剔骨针。

黄金格只认“参与阵型后被消除”：

- 剔骨针直接移除黄金格里的符号，不会立即领取赏金。
- 直接移除后，标记仍保留在原位置；之后落入该格的符号如果参与阵型消除，正常领奖。
- 标记格只要属于实际中奖消除范围，三连等小阵型也可以领奖，不要求五连。
- 同一轮该格涉及多个判定，黄金赏金也只支付一次；支付时标记立即消耗。

已有未领取标记时，不能再放第二个，也不能免费移动原标记。选择目标前取消不扣道具；成功放置后不可撤回道具。

再次拉杆会清除未领取标记。状态提示应一直写明“本盘有效，再拉杆失效”，不依靠额外确认弹窗告知。

**界面文案：**“标记当前一格。它在下次拉杆前参与阵型消除时，额外获得本盘基础费用的 100%，限一次。”

**示例：**本盘 B = 8，在一枚弓所在的格子放置黄金标记。随后剔骨针移除这枚弓，不发奖；上方的刀落入该格并组成五连，此时发放基础五连 16 加黄金格 8，共 24 骨头，另照常获得士兵。

## 8. 剔骨针

**用途：移除一个阻碍符号，用已知的下落位移与未知的补入符号重新寻找阵型。**

| 项目 | 规则 |
|---|---|
| 使用对象 | 当前静止残盘的一格符号 |
| 操作 | 点击剔骨针，选中可操作格；点击目标格即执行 |
| 消耗时点 | 有效目标的移除开始时消耗 1 根 |
| 直接效果 | 移除该格符号；被移除的符号不产生士兵、骨头或消除轮数 |
| 下落规则 | 目标上方符号各下降一格，目标下方不动，最顶部按当前符号池补入 1 个新符号 |
| 后续结算 | 下落完成后检查整个盘面；有阵型就自动结算、消除、补新，直到静止 |
| 费用与次数 | 不付骨头、不增加拉杆次数、不改变下一次报价；每次操作消耗 1 根 |

选中道具后，应预览受影响的列与已知符号的移动位置；顶部新符号保持未知。取消选择不消耗道具。开始移除后，不能撤销，也不能在下落中插入下一根针。

如果剔除最上方符号，没有旧符号移动，只补入一个新符号。无论选择哪格，最初都只补一个新符号；后续阵型引发的消除则按正常规则补入相应数量。

剔骨针不会改变符号池权重，也不保证一定成阵。若补新后仍没有阵型，道具照常消耗，老虎机回到静止；空转保险不赔付这次操作。

完整结算后，可以继续用另一根针。每次针引起的连锁独立计数，但沿用同一盘 B、已生效的点名目标及连锁悬赏是否领过的状态。

**界面文案：**“移除一格，不获得直接奖励。上方符号下落，顶部补入一个新符号；成阵后自动结算。”

**示例：**一行是“刀、刀、弓、刀、刀”，弓上方正好是刀。剔除弓，上方刀落下，形成横排五连。针本身不奖励弓兵；五连照常奖励剑士及骨头。

## 9. 组合与判定口径

### 9.1 允许组合，但各自只计算自己的效果

| 组合或场景 | 判定结果 |
|---|---|
| 半价券＋锁价齿轮，报价 8 | 实付 4，之后报价 8，本盘 B 仍为 8 |
| 半价券＋空转保险，报价 8 | 实付 4；完全无阵型时退 2，不能按原价退 4 |
| 锁价齿轮＋空转保险 | 空转时正常退款，且不涨价；这不是退回已经上涨的价格 |
| 点名赌约＋半价券 | 付款减少；指定五连奖金仍按未打折 B 计算，这是允许的组合收益 |
| 点名赌约＋空转保险 | 有任意有效阵型就不赔，即使没有押中指定兵种 |
| 点名赌约＋黄金格 | 指定五连 6B 可再加黄金格 B；非指定五连也可单独获得黄金格 B |
| 点名赌约＋连锁悬赏 | 押错兵种仍可达成悬赏，两者判定相互独立 |
| 黄金格＋剔骨针 | 针直接移除不领奖；固定格位后来参与阵型消除才领奖 |
| 连锁悬赏＋多根剔骨针 | 每根针都可以开启新的尝试；每次从 0 计轮数，本盘悬赏最多支付一次 |
| 当前残盘上准备新赌约，再使用针 | 新赌约继续等待下一次拉杆；当前针仍按原有本盘规则结算 |
| 骨头为 0，仍有黄金格与剔骨针 | 可以使用；得到的钱可以用于下一次拉杆，报价不因道具结算再翻倍 |
| 新拉杆因钱不足而未启动 | 当前黄金格与本盘赌约都保留，准备道具不消耗 |

这些组合的收益可以较高，代价是预先准备与消耗有限道具。首版不把允许的联动当作需要取消的效果；平衡时同时观察道具供应、骨头奖金和士兵回收收入。

### 9.2 自动结算顺序

每一轮按下列顺序自动完成，步骤之间均不可操作：

1. 在当前盘面按现有阵型优先级确定实际中奖阵型及消除格。
2. 本次自动结算的消除轮数加 1。
3. 用消除前的同一份盘面，确定横排骨头奖、黄金格及连锁悬赏是否触发。
4. 发放各阵型的士兵、横排骨头奖、黄金格赏金和悬赏；记录已经领取的单次奖励。
5. 消除中奖符号，下落并补新，再回到第 1 步。
6. 无新阵型后结束循环。若这次过程由付费拉杆启动，再完成空转保险判定与可能的退款。
7. 所有相关结算与动画结束，恢复道具和拉杆操作。

需要保留到本盘结束的信息只有：本盘 B 与 P、已生效的点名目标、连锁悬赏是否仍可领取，以及尚未领取的黄金格位置。每次自动结算的消除轮数单独从 0 开始。

下一次成功拉杆开始时，先结束旧盘效果，再建立新的 B、P 与本盘效果。旧盘没领到的悬赏和黄金格不跨盘补发。准备道具是单独等待下一次拉杆的状态，不因旧盘一次道具结算而被清空。

## 10. 完整体验例子

### 10.1 费用保护

当前报价 8，玩家准备半价券、锁价齿轮和空转保险。

- 拉杆实付 4，这三件准备道具正式消耗。
- 下一次报价保持 8，本盘奖金基数也是 8。
- 如果整次完全没有阵型，保险自动退 2，玩家净支出 2 骨头。
- 此时盘面仍保留，后续可以用黄金格与剔骨针救盘。
- 之后剔骨针即使落空，也不再触发保险；救出阵型则正常领奖。

### 10.2 没钱后，用黄金格与剔骨针救盘

上一把未打折票价 B = 8，下一次报价 16，玩家剩余 0 骨头。本盘没有点名赌约。以下是已经完整结算、没有阵型的残盘；“杖”表示法杖：

| 行／列 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | 弓 | 盾 | 刀 | 马 | 杖 |
| 2 | 刀 | 刀 | 弓 | 刀 | 刀 |
| 3 | 马 | 弓 | 杖 | 盾 | 弓 |
| 4 | 盾 | 杖 | 马 | 弓 | 杖 |

1. 玩家给第 2 行第 3 列放置黄金格，消耗 1 份道具，盘面仍静止。
2. 玩家用剔骨针移除该格的弓，消耗 1 根针，自动过程立即开始。此时不领取黄金赏金。
3. 第 1 行第 3 列的刀落下，顶部补入一个未知符号；黄金标记仍在第 2 行第 3 列。
4. 第 2 行形成五把刀，按现有直线阵五规则获得 4 张剑士卡，并获得横排奖 16 与黄金格赏金 8，合计 24 骨头。
5. 自动消除、下落并继续检查连锁；黄金标记已领取并消失。期间不能使用其他道具。
6. 全部结束后恢复操作。忽略后续可能出现的额外奖励，玩家至少有 24 骨头与新增 4 张剑士卡；下一次报价仍是 16。

玩家可以继续花 16 拉杆，也可以保留兵力和骨头结束招募。救盘过程本身没有增加一次拉杆费用。

### 10.3 赌约、黄金格与悬赏一起触发

本盘 B = 8，拉杆前已经准备点名剑士的赌约和连锁悬赏。首次完整结算后尚未达成悬赏，玩家在残盘使用黄金格与剔骨针。

如果这次针引起的自动结算中，恰好只有一行指定剑士五连、黄金格被消除一次，并连续消除到第三轮：

- 指定五连：6B = 48 骨头，不再加基础五连的 16。
- 黄金格：B = 8 骨头。
- 连锁悬赏：3B = 24 骨头。
- 本次额外骨头合计 80，士兵仍按各阵型正常获得。

本盘之后再形成指定五连，仍可领取横排奖；悬赏已经领过，不再支付。要再次放置黄金格，必须消耗另一份黄金格道具。

## 11. 首版数值与后续试玩重点

| 参数 | 本稿建议值 |
|---|---|
| 默认拉杆涨价 | 每次成功拉杆后 ×2 |
| 半价券折扣 | 50%，付款向上取整，最低 1 |
| 锁价齿轮 | 取消一次涨价 |
| 空转保险 | 返实付 50%，向下取整；退款为 0 时不使用 |
| 基础横排五连奖 | 每行本盘基础费用的 200%，即 2B |
| 点名赌约 | 指定兵种每行本盘基础费用的 600%，即 6B；其余横排 0 |
| 连锁悬赏门槛／奖金 | 单次连续 3 轮／本盘基础费用的 300%，即 3B；每盘一次 |
| 黄金格赏金／同时数量 | 本盘基础费用的 100%，即 B／最多 1 个未领取标记 |
| 剔骨针 | 每根移除 1 格，最初补入 1 个新符号 |

后续试玩优先观察三件事：没钱时剔骨针是否提供有价值的救盘判断；玩家能否理解折扣实付、票价奖金和保险退款的区别；骨头奖与士兵回收叠加后，是否使继续拉杆的成本失去压力。

## 12. 比例奖金与通胀控制

比例奖金保证同一类中奖在后期仍有价值。它同时会随票价放大骨头产出，因此不能把“奖励按比例成长”本身当成通胀已经解决。

一个明确反例：如果每次拉杆都保底返回本次基础费用的 200%，玩家支付 B 后拿回 2B，就总能支付下一次的 2B。即使费用不断翻倍，只要这个保底不断，玩家仍能一直拉。普通阵型又产生士兵时，还会继续积累兵力。

因此，费用翻倍用于消耗旧余额的购买力，奖励是否能持续覆盖新费用，则取决于中奖次数、奖励比例和道具供给。本稿建议把约束落在以下位置：

1. **把 200% 留给有条件的五连，600% 留给押中的指定五连。** 普通阵型照常给兵，不把每个小阵型都变成足够支付下一次的现金奖。高额骨头收入应当来自具体命中、连锁或消耗品操作。
2. **按完整盘面观察收益。** 自然连锁、残盘上的全部剔骨针收益、黄金格和保险都要计入，不能只看首次拉杆结算。普通、无消耗品、尚未成型的构筑，优先以平均直接骨头回流低于拉杆支出作为起始调参目标；这是设计目标，不是已测得的结果。
3. **把回收与道具买卖纳入整场招募的收支。** 获得士兵不直接发骨头，但之后回收会产生货币。消耗品组合可以短时赚回超过投入的骨头，其强度必须连同取得代价计算，不能只比较单张道具的百分比。
4. **建议每场招募的道具补给有限。** 尤其不能在同一个高价残盘上，以固定的早期低价无限补买黄金格和剔骨针，再反复兑换按高额 B 计算的奖金；这个循环没有新拉杆，费用翻倍约束不到它。商店具体售价另定，首版应限制场内补给，不提供单盘无限低价补货。
5. **构筑提升后的高回报可以保留。** 符号池集中、万能符号和空间操作都会提高中奖能力。先观察它们让每盘合格横排数、连锁次数和骨头回流增加了多少，再调整比例或供给；不在开奖后临时降低本盘已经确定的奖金，也不重复计算同一组已消除符号。

第一轮试玩先使用 200%／600%／300%／100% 这组比例，验证“一次五连够再拉一把，一次指定大奖够付后续两把”的体验。若普通局面也长期不断续拉，优先检查触发频率、有限道具是否被无限补给、回收收入和重复结算，再决定是否降低具体比例。

道具售价、掉落频率、库存上限、稀有度，以及拉杆价格在战斗之间如何重置，仍需与整体招募与战斗经济一起确定；以上比例和供给边界是当前推荐方案，尚未经试玩验证。
