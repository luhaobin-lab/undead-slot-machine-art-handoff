## 1. 游戏概述

**一句话**：玩家是亡灵领主，用骨头拉一台「亡灵老虎机」召唤亡灵军团，军团自动和人类军队打仗；赢了拿遗物、去集市把老虎机越做越大，从乱葬岗一路打进白冠王都。

| 项目 | 内容 |
|---|---|
| 类型 | 肉鸽（Roguelike）+ 老虎机构筑 + 自动战斗（灵感：《How Many Dudes》的自动战斗、《杀戮尖塔》的地图与营火、《Luck be a Landlord》式老虎机构筑） |
| 平台 / 输入 | 浏览器，1600×900 固定舞台按窗口等比缩放；鼠标为主，键盘：空格 = 拉杆、B = 阵型图鉴、1–6 = 老虎机道具、1–3 = 战斗道具、商店里 WASD 走动 / 按住 E 购买、F = 全屏、Esc = 取消 |
| 一局时长 | 完整三章约 22 分钟；速通（跳过第二章）约 14–16 分钟 |
| 阵营 | 我方：12 种可招募的亡灵（不死族）+ 召唤物白骨仆从；敌方：中世纪人类军队 65 种 + 11 个首领单位 |
| 核心体验 | 每场战斗前「拉老虎机凑阵型 → 决定拉几次、用什么道具、怎么排列」，然后看军队自动打；战间在集市里让老虎机更容易出想要的兵 |

**设计主张**（来自原始设计稿）：敌人的机制让玩家想改变构筑，而符号、遗物和道具真的提供这种改变。游戏的选择分三个时间尺度：

| 时机 | 玩家改变什么 | 看得到的结果 |
|---|---|---|
| 战间（集市 / 篝火） | 盘面大小、符号构成、兵种、阵型倍率、道具、遗物 | 下一场更容易出现想要的兵，或出现新的触发关系 |
| 本场整备（准备阶段） | 拉几次、用什么老虎机道具、左右怎么排列、回收哪一列 | 同一个构筑产生不同的兵量与邻接关系 |
| 自动战斗 | 何时、往哪扔战斗道具（扔的时候时间停止） | 及时炸、冻、复活、召唤，接上已有的触发链 |

**战后兵散**：每场战斗开始时军队清零，士兵不跨战保留。跨战保留的只有：老虎机（盘面、符号）、兵种、遗物、道具、货币和命。

## 2. 一局的流程

```
标题（图 01）
  └─ 开局三选一：选一个「亡灵军团」（3 个兵种 + 核心遗物）（图 02）
      └─ 教学战「守墓人小屋」（第一转保证出阵，图 03–07）
          └─ 第一章地图（7 层 + 首领 + 大集市）→ 第二章 → 第三章（图 10–14）
              每个节点：战斗 / 精英 / 集市 / 篝火 / 乌鸦赌场 / 首领
              战斗节点：准备阶段（拉老虎机）→ 自动战斗 → 结算 → 遗物三选一
          └─ 终章「白冠王都」：三波连打（外城城门 → 王宫正门 → 王座厅），中间不进商店
              └─ 结局：通关 / 失败（图 49–50）
```

- **标题**：选难度（轻松 ×0.8 / 标准 ×1 / 困难 ×1.2 敌军战力）和局长（完整 / 速通）。
- **开局军团**：8 组预设里随机给 3 组（见 [04 §1.1](04_数据附表.md#11-开局军团8-组每局随机给-3-组选)）。每组 3 个兵种已经能连上触发；起步慢的 4 组（骷髅接力、治疗转伤害、傀儡成长、号令积咒）开局自带 1–2 件核心遗物。
- **章节**：三章各一张地图。每章的路线都是 7 层：第 1 层普通战、第 4 层集市、第 7 层篝火（首领前），第 2 / 3 / 5 / 6 层随机；然后是首领、首领后的大集市，再进入下一章。第三章大集市之后是终章。
- **速通**：第一章大集市之后直接进第三章，第三章按第二章的深度算敌人强度（首领 ×0.98、王都 ×1.1 保持高潮紧张度）。
- **结局**：王都第 3 波（国王）打赢 = 通关；命用完 = 失败。显示用时、胜场、击败人类数、最大军队、遗物数、灵魂数。

## 3. 资源与经济

| 资源 | 用途 | 怎么得到 | 跨战保留 |
|---|---|---|---|
| **骨头** 🦴 | **只用来拉老虎机**（拉杆费用 1 → 2 → 4 → 8 …） | 战利品、残部返还、熔炉回收士兵、老虎机奖励（横排五连 / 黄金格 / 连锁悬赏 / 保险）、乌鸦赌场 | 是 |
| **灵魂** 🔮 | **只在集市用**（新兵种、符号、扩盘、老虎机道具、战斗道具、刷新） | 战斗奖励（按节点风险）、遗物三选一跳过 +5 | 是 |
| **命** ❤ | 输一场扣 1 条，换一次「时间倒流」重打；用完 = 整局失败 | 开局 3 条，只有篝火「休息」能 +1（上限 5） | 是 |
| **遗物** | 永久被动效果（94 件） | 每场战斗胜利后三选一（不能买） | 是 |
| **士兵** | 这一战的军队 | 老虎机成阵召唤、招魂幡 | **否**（每战清零） |

### 3.1 骨头的锚点公式

骨头的设计目标是「每战能拉几次」：

- 每战目标拉杆次数 `T(d) = 5 + 5.5 × (d / 32)^1.1`（d = 节点深度，第一章约 5–6 次，王都约 10 次）。
- 节点战利品 `loot(n) = round(2^T(n.d + 1.5) × 0.9)`；教学战固定 31。
- 拉 k 次的总费用是 `2^k − 1`，所以「骨头 B 能拉几次」= `floor(log2(B + 1))`（结算面板会显示「下一战能拉 N 次」）。
- **每战开始至少 15 骨头**（不够时守墓乌鸦补足，保证能拉 4 次：1+2+4+8）：连空 3 次后第 4 次是大奖转，所以不会出现一个兵都没有的死循环。
- 每战最多拉 15 次（安全阀，正常玩碰不到）。

| 深度 d | 0 | 4 | 8 | 12 | 16 | 20 | 24 | 28 | 32 |
|---|---|---|---|---|---|---|---|---|---|
| 目标拉杆次数 | 5.0 | 5.6 | 6.2 | 6.9 | 7.6 | 8.3 | 9.0 | 9.6 | 10.5 |
| 战利品（骨头） | 33 | 52 | 82 | 129 | 210 | 341 | 551 | 885 | 1426 |

（精确值见 `data/shops.json → economy.pullTargetSamples`。）

### 3.2 战斗结算

- **胜利**：骨头 = 战利品 + 残部返还；残部返还 = `round(战利品 × 0.5 × 存活率)`，存活率 = 存活的在册士兵（含倒下的饥腐行尸，它们会爬起来）/ 出战的在册士兵。
- **灵魂**按节点风险发（v3 起没有连胜倍率）：教学战 25 · 普通战 6 · 精英 36 · 首领 35 · 王都 0。
- **失败**：没有战利品、没有灵魂，扣 1 条命并时间倒流（见 §13）。
- **击杀飘字**：每杀一个人类，头顶飘 `+N🦴`（战利品按这个人类的战力占比分摊，只是展示）。
- **熔炉回收**：准备阶段把一列士兵拖进骨灰熔炉，每名换 `max(1, round(战利品 / 30))` 骨头（随章节涨）。

## 4. 亡灵老虎机

老虎机是整个游戏的核心。界面见图 04–06、25–31。

### 4.1 盘面

- 开局 **3 列 × 3 行**，在集市的「亡灵老虎机仪式」买「盘面升级」：每次 +1 列或 +1 行（方向随机，刷新能换），最终 **5 列 × 4 行**。三次升级的价格 30 / 45 / 60 灵魂。
- **列数不能超过兵种数**（想横着扩盘，先在墓园招一种兵）。不加这条，「3 种兵 + 5×4」的出阵率高达 90%，招新兵就成了陷阱。
- 格子 76×76、间距 6、内边距 12；没开放的区域显示斜纹锁。盘面居中：`left = 21 + (5 − 列数) × 41`，`top = 116 + (4 − 行数) × 41`（机身内坐标）。

### 4.2 符号池与抽符号

- 每个兵种在符号池里有若干张符号：**招募时 4 张**，在墓园可以 +2（上限 12）或「迁坟」−1（下限 2）。万能符号最多 1 张（墓园 30 灵魂）。
- 每一格独立抽：`P(符号 s) = 张数(s) / 符号总数`。所以**兵种越多，每种的占比越低、越难凑阵**（这是招新兵的代价）。
- 「定向砝码」生效的那一转，指定兵种的张数按 2 倍算。

### 4.3 拉杆费用

- 每战第 1 次 1 骨头，之后每次翻倍：1 → 2 → 4 → 8 → 16 …（`2^次数`），**每场战斗开始重置为 1**。
- 半价券：这一次实付 `max(1, ceil(报价 / 2))`（奖金仍按原价 B 算）；锁价齿轮：这一次拉完报价不翻倍。

### 4.4 阵型（16 种）

同一种符号（万能可以顶任意一种）排成以下形状就「成阵」，召唤 **倍率** 名该兵种士兵：

| 阵型 | 倍率 | 形状 | 阵型 | 倍率 | 形状 |
|---|---:|---|---|---:|---|
| 直线阵3 | ×1 | `XXX` | 大十字阵8 | ×10 | `..X.. / XXXXX / ..X.. / ..X..` |
| 直线阵4 | ×2 | `XXXX` | 密集阵4×2 | ×12 | 4×2 实心 |
| 方阵2×2 | ×3 | 2×2 实心 | 密集阵5×2 | ×16 | 5×2 实心 |
| 直线阵5 | ×4 | `XXXXX` | 方阵3×3 | ×20 | 3×3 实心 |
| 十字阵5 | ×5 | `.X. / XXX / .X.` | 密集阵4×3 | ×30 | 4×3 实心 |
| 密集阵3×2 | ×6 | 3×2 实心 | 密集阵5×3 | ×40 | 5×3 实心 |
| 骨爪阵(C形) | ×8 | `XXX / X.. / XXX`（方向固定） | 方阵4×4 | ×60 | 4×4 实心 |
| 骨爪阵(反C形) | ×8 | `XXX / ..X / XXX`（方向固定） | 全军阵5×4 | ×100 | 5×4 全满 |

- 除两个骨爪阵外，所有阵型都可以旋转（90° ×4）和镜像；盘面放不下的变体自动去掉（阵型图鉴里变灰，图 36）。
- 在**篝火**可以把某个阵型的倍率永久 +1（`倍率 = 基础 + 升级次数`）。

### 4.5 判定算法（`findMatches`）

贪心、不重叠：

1. 预先生成所有阵型的所有变体（旋转 / 镜像去重、去掉放不下的），按**倍率从高到低、格数从多到少**排序。
2. 从头扫描变体列表，在盘面上逐个位置尝试：这个变体覆盖的格子都没被占用，且非万能格都是同一种符号（至少有一个非万能格） → 记为一个阵型，把格子标记为已用，**回到列表开头**重新扫描。
3. 扫完整个列表都找不到新阵型时结束。

所以一个盘面会优先认出最大的阵型，剩下的格子再找小阵型。万能格可以被多个候选看到，但一旦被某个阵型占用就不能再用。

### 4.6 一次拉杆的完整结算（`spin` → `resolveBoard`）

1. **付费**：报价 B（未打折）、实付 P；消耗所有「已准备」的准备类道具；骨头 −P；报价翻倍（除非锁价）。
2. **出盘**：每格按符号池抽（定向砝码 ×2、定轴钉那一列保持不动）；如果幸运灯全亮 → 大奖转（§4.7）；教学战第一转是固定的必出阵盘面。
3. **转轴动画**：各列从左到右依次停（普通：第 c 列 `750 + 260c` 毫秒；大奖转：`1100 + 560c` 毫秒，一列一列慢慢停）。
4. **连锁循环**（直到没有阵型）：
   1. 判定所有阵型（§4.5）。
   2. 用消除前的盘面计算骨头奖励：
      - **横排五连**（只有 5 列时才有）：某一整行 5 格都在本轮被消除、且是同一种符号 → +2B 骨头；如果押了「点名赌约」：押中的兵种每行 +6B，其余行 0。
      - **黄金格**：被标记的格子参与消除 → +B（一次）。
      - **连锁悬赏**：本次拉杆的连锁达到第 3 轮 → +3B（一次）。
   3. 逐个展示阵型（高亮 + 标签，×10 起机身抖动，×20 起全屏闪光 + 横幅），召唤的士兵飞进对应兵种的列。
   4. 消除成阵的格子，上面的符号下落，顶部补新符号（按符号池抽）。
5. **空转保险**：这一次拉杆 0 个阵型 → 退还 `floor(P × 0.5)` 骨头。
6. **幸运灯**：这一次 0 个阵型 → 点亮一盏（最多 3）；有任何阵型 → 全灭。

### 4.7 幸运灯与大奖转

- 平时完全走正常概率。连续 3 次付费拉杆都没出阵，三盏灯全亮（拉杆球头变金色）。
- 下一次拉杆是**大奖转**：先正常随机出盘，再在随机位置覆盖一个**倍率 ≥ ×6** 的阵型。阵型的权重 = `1 / 倍率`（越大越少见），只从当前盘面放得下的阵型里选；符号按兵种的符号张数加权选（不会是万能）。
- 3×3 盘面能出的大奖只有密集阵3×2（×6）、骨爪阵（×8）和方阵3×3（×20）。
- 「幸运灯芯」道具可以立刻点亮一盏。

### 4.8 老虎机道具（14 种，6 格道具栏）

道具栏 6 格，同种叠放（右下角数量）。只在老虎机**静止**时能用。三类：

| 类型 | 道具 | 规则 |
|---|---|---|
| **准备类**（点一下准备，下一次拉杆时消耗；再点取消） | 半价券 | 这次实付减半（最低 1），奖金按原价算 |
| | 锁价齿轮 | 这次拉完报价不翻倍 |
| | 空转保险 | 这次 0 个阵型 → 退实付的 50%（向下取整；退 0 时不能准备） |
| | 点名赌约 | 押一个兵种：横排五连押中每行 6B、没押中的行 0；士兵照常 |
| | 连锁悬赏 | 这次连锁到第 3 轮 → +3B |
| | 定轴钉 | 选一列：下一转这一列不动 |
| | 定向砝码 | 押一个兵种：下一转它的符号概率翻倍 |
| **选格类**（作用于当前盘面，需要先付费拉过一次；不付骨头、不增加拉杆次数） | 黄金格 | 标记一格：它在下次拉杆前参与消除 → +B（每盘一个） |
| | 剔骨针 | 移除一格，上方下落、顶部补 1 个新符号，再自动结算 |
| | 微调摇把 | 一列往下转一格（最下面的转到最上面），不出新符号，选列时就能预览结果 |
| | 换位钩 | 交换相邻（上下左右）两格，预览结果 |
| | 单列重转 | 这一列重新随机，再自动结算 |
| **立刻类** | 幸运灯芯 | 立刻点亮一盏幸运灯 |
| | 招魂幡 | 选一个兵种，立刻召唤 2 名 |

价格（灵魂）：半价 6、锁价 8、保险 6、赌约 8、悬赏 8、黄金格 8、剔骨针 10、定轴钉 8、微调 8、换位 10、单列重转 8、砝码 10、灯芯 8、招魂幡 8。

## 5. 准备阶段

图 03、32–35。每个战斗节点进来先到这里：

- **双方各 5 列**：左边 5 列是我方兵种（**右边是前排**，新兵种从最左边 = 后排加入；还没开放的位置显示「去墓园招募新兵种」），右边是敌方（每种敌人一列，index 0 在最左 = 前排）。列头显示图标、×数量、名字；每列最多画 20 名，多的显示「+N 名」。

## 6. 自动战斗

图 07、39–46。开战后所有单位在 1560×566 的战场里自由移动（`FIELD x 20–1580、y 150–716`），横幅「开战！」0.9 秒后开始。右下角可切换 ×1 / ×2 速度。

### 6.1 单位属性模型

每个单位有：基础属性（生命、攻击、攻速、移速、射程 30）+ 四类修正：

| 修正 | 合并方式 | 用于 |
|---|---|---|
| `add` 永久加成 | 相加 | 攻击% / 攻速% / 移速% / 生命% / 顺劈 / 再生 / 吸血 / 受治疗% / 易伤 … |
| `dim` 收益衰减类 | `1 − Π(1 − xᵢ)`（不同来源相乘，不会到 100%） | 暴击、偏转、韧性、格挡、闪避、失手 |
| `buffs` 独立计时增益 | 每层单独计时，同 key 可设上限 | 号令、号角、各种限时效果 |
| `stacks` 叠层 | 共享一个计时，叠加时刷新 | 毒、雷印类、光环 |

- 攻击 = 基础 × max(0.1, 1 + Σ攻击%)；攻速 = 基础 × max(0.1, 1 + Σ攻速% + 狂热)；移速（像素 / 秒）= 展示移速 × (1 + Σ移速%) × 6。
- 暴击倍率 = 1.5 + 暴击伤害加成。
- **临时生命**：一组带过期时间的护盾，受伤时先扣最早过期的（穿透比例的伤害绕过它）。

### 6.2 每帧流程（`step(dt)`）

1. 推进投射物（追踪 / 定点），落地时结算。
2. 每 0.5 秒 `halfTick`：重新计算依赖周围人数的动态加成（群聚、同袍等）、瘟烟区域、均摊生命等。
3. 推进号角冲击波；计算双方前线位置和每个单位被几个人围攻（`aiFrame`）。
4. 每个活着的单位依次：
   1. 每秒 `secondTick`：再生、血泵、燃烧等。
   2. `abilities`：兵种技能计时器（召唤、脉冲、派送、魂光、火球、号令、嘲讽）/ 敌军特性计时器。
   3. 特殊移动接管：车阵跟随 → 被击飞（抛物线）→ 眩晕（不动）→ 缠杀 → 冲锋 / 乱冲 / 连斩 / 扑击。
   4. **选目标**：冲刺锁定 > 追猎 > 被嘲讽（嘲讽者）> 战术选择（每 0.4–0.8 秒重新评估一次）。
   5. **移动**：按角色（§6.3）走位；进入射程就站定。
   6. **攻击**：在射程内且冷却到了 → 攻击（冷却 = 1 / 攻速），带顺劈。
5. **黎明鏖战**：开战 80 秒后，每 5 秒所有单位受到「最大生命 × 3% × 第几次」的真实伤害（防止僵持；第一次有横幅提示）。
6. 一方全灭 → 战斗结束，0.8 秒后弹结算。

绘制时所有单位按 y 坐标从上到下排序（远的先画），每个单位：脚下影子 → 嘲讽框 → 精灵（受击抖动 + 闪白、死亡 0.6 秒淡出下沉、被击飞抛起 26px）→ 头顶血条 / 临时生命 / 墓咒条 → 状态标记。

### 6.4 伤害管线（`damage`）

一次伤害按顺序经过：

1. **可被规避的伤害**（不是真实 / 转移 / 释出伤害）：攻击者失手？→ 目标闪避？→ 直接伤害被格挡？→ 目标偏转（自己不受伤，50% 作为直接伤害转给生命更高的队友）？
2. **暴击**（可暴击的伤害）：概率 = 攻击者暴击率 + 目标的「被暴击」加成；伤害 × 暴击倍率。
3. **易伤**：× (1 + 目标易伤%)（真实伤害除外）。
4. **韧性**：× (1 − 韧性)（真实 / 转移伤害除外）。
5. **缚命巫妖**：巫妖受到的伤害 70% 存进左边一列兵（傀儡）体内（每名傀儡上限 200% 最大生命），每 3 秒作为真实伤害释出；致命时傀儡回复 50% 生命并获得一层「还魂怒火」。
6. **敌方分担**：「同袍分伤」把 30% 转给最多 2 名同类；千垒督军「尾节护阵」把 99% 转给最后一节护卫车。
7. **临时生命**吸收（穿透比例绕过）。
8. 扣生命；记录统计；触发「造成伤害后」（吸血、墓咒、雷印、厨师做羹……）和「受到伤害后」（缝补、胸甲、敌军受伤特性）。
9. 生命 ≤ 0 → **致命伤**：先尝试救援（兵种专属自救 → 友方救援，第一个成功的生效），救不了 → 击倒。
10. 咒布古尸的墓咒：目标生命 < 墓咒值时释出全部墓咒。

**治疗**单独一条管线：× (1 + 受治疗%)，可暴击（部分来源），溢出部分可能变成临时生命；饥腐行尸受到治疗时 15% 概率嘲讽附近 3 敌。注意：捐赠（血泵）、抽取、生命均摊**不算治疗**。

## 8. 敌军强度：预算与心流

敌军不是手配人数，而是按「战力预算」生成：

- **单兵战力** `pw = √(生命 × 攻击 × 攻速)`（兰彻斯特平方律：一支军队的战力 ≈ Σ 人数 × √(生命 × 秒伤)，可以直接相加）。
- **基准线** `PAR(d) = 787 × 1.0757^d`：中等策略机器人在深度 d 打普通战时 50% 胜率的敌方战力（v3 地图 + 新老虎机，探测倍率 0.35–8 × 64 局校准）。
- **心流系数 F**：本节点敌方战力 = PAR(d) × F（F = 1 是 50% 胜率线）。

| 节点 | 第一章 | 第二章 | 第三章 | 目标胜率 |
|---|---|---|---|---|
| 普通战（第 1 层 → 首领前线性插值） | 0.26 → 0.38 | 0.31 → 0.34 | 0.31 → 0.35 | 约 94% |
| 精英 | 0.50 | 0.52 | 0.41 | 约 80–85% |
| 首领 | 0.55 | 0.48 | 0.55 | 约 75% |
| 王都三波 | 0.61 / 0.62 / 0.36 | | | |

- **预算** = PAR(d) × F × 节点倍率（个别遭遇 0.9）× 难度 × 速通修正。
- **换成人数**：遭遇有 k 种敌人时按份额分预算（2 种 60/40、3 种 50/30/20、4 种 40/25/20/15、5 种 35/25/15/15/10），`人数 = max(1, round(预算 × 份额 / pw))`。
- **上限 70 人**：超过时人数按 k = 总数/70 缩减，单兵生命和攻击各 × k（「精兵 ×k」，总战力不变）。
- **首领战**的预算分配：千垒督军 30% 车首 + 36% 车厢 + 34% 护卫；铁冠 30% 本体 + 70% 护卫；圆桌 52% 六骑士 + 48% 护卫；王座厅 25% 国王 + 7% 继承人 + 68% 近卫。
- 深度 `d = 章节起点 + (节点 x − 90) / 141`；章节起点 0 / 11 / 22（速通时第三章 11）。敌人强度只看深度，和走哪条路无关。

## 9. 地图生成

图 10–14。每局重新生成，杀戮尖塔式，每章 5 条车道 × 7 层：

1. 画 5 条路：每条从第 1 层随机车道出发，每层走到相邻车道（−1 / 0 / +1），**不和左右车道已有的路交叉**；前两条路起点不同。

## 10. 集市（三家店）

图 15–20。集市是一个**可以走动的横版场景**：玩家化身（亡灵领主）在地面走（点地面或 WASD），三家店从左到右排开，每家有店主、货架、刷新物件；右边是离开的门。

**交互**：鼠标移到商品上看说明（或键盘走近自动聚焦）；**按住 0.5 秒购买**（价签下面一圈进度环，按 E 也行）；买到的东西飞向化身，店主说一句话。离开时如果还有买得起的东西会提醒一次（再点一次门才走）。商店不卖遗物、不卖命、不卖阵型倍率。

| 店 | 店主 | 货架 | 刷新物件 / 底价 |
|---|---|---|---|
| **墓园** | 掘墓人 | 3 口棺材（新兵种，第 4 种 22、第 5 种 32 灵魂）+ 3 块墓碑（某兵种符号 +2 张 8 灵魂 / 迁坟 −1 张 6 灵魂起每用一次 +4 / 万能骨符 30 灵魂） | 守墓铃 4 |
| **亡灵老虎机仪式** | 仪式祭司 | 1 个盘面升级（+1 列或 +1 行，30 / 45 / 60）+ 3 个老虎机道具；升满 5×4 后升级位换成第 4 个道具 | 仪式骨钟 5 |
| **战斗道具商人** | 军需骷髅 | 3 个战斗道具（10–14） | 翻货箱 3 |

- **刷新**：每家店自己刷新，价格每次翻倍（墓园 4 → 8 → 16、仪式 5 → 10 → 20、商人 3 → 6 → 12），**每次进店重置**。刷新把这一家的商品全部换新（买走的也补上），所以有钱可以买 3 个 → 刷新 → 再买 3 个。
- **价格浮动**：每件商品 × 0.92–1.08；每次进店随机一件（盘面升级除外）**半价特价**。
- **货架生成规则**：
  - 棺材：已有 5 种兵时换成符号；优先出现一个能和现有兵种组成「开局军团」组合的兵种。
  - 墓碑：+2 符号（权重 1 + 张数/4 + 越靠前排越高）、迁坟（权重 0.45，张数 > 2 时）、万能（权重 0.9，还没有时）。
  - 盘面升级：在能加列（列数 < min(5, 兵种数)）/ 能加行（行数 < 4）里随机一个方向。
  - 同一家店里不重复。

## 17. 已知问题与待定方向

（来自 v3.1 验收，等用户定方向，**不影响美术制作**。）

1. **「只用开局 3 种兵」是压倒性最优解（通关 100%）**：兵种越少，同种符号越容易连成大阵，概率按阵型格数成指数涨；同样 4×4，3 种兵每转平均出 4.4 名，5 种兵只有 1.0 名。候选修法：A 赔率按稀有度（推荐，需要再做一轮实验）/ B 编制加成 / C 限制单一兵种占比 / D 新兵种只带 2 张符号。
2. **新手（随机乱买）通关率只有 15%**：主要是没买盘面升级（到第三章首领时约四成还停在 3×3）。已加「★ 扩盘」标记和稀释提示，需要真人试玩确认。
3. 「还魂骨袋」「牛至叶」两件遗物只实现了战内部分。
4. 我方单位的像素图是正面像、不左右翻转；敌人朝左并会翻转（新美术建议我方也做侧身，见 03 号文档）。
5. 敌人 id 用的是原资料的动物编号（见 §7.2），只是内部编号，玩家看不到。
