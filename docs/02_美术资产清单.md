**最重要的三条约束**（详见 03 号文档 §2）：

1. **敌人 id 是动物名，但本作里全是人类士兵**。`duck`、`wolf`、`gorilla` 这些 id 沿用了原始资料的编号，画的时候按「名称」和「外观」画中世纪人类（民兵、步兵、骑士、攻城车、国王），**不要画动物**。
2. **每个兵种的主色是界面语义色**：列头描边、符号池色条、统计表、遗物色块都用它。新美术请保留每个兵种的主色（表里的 `keyColor`），12 个兵种之间要能靠颜色 + 轮廓一眼区分。
3. **同屏单位很多、显示很小**：战斗里我方单位约 40×47 像素、人类约 53×48，一场首领战能有 100+ 个单位同时混战；老虎机符号 62×62，要在 5×4 盘面里一眼认出 12 种兵 + 万能。轮廓、色块对比优先于细节。

## 1. 我方亡灵（12 兵种 + 白骨仆从）

每个兵种要 **两样**：①战场形象（带动画，准备阶段的人群和自动战斗都用它）；②老虎机符号（也是它在所有界面里的头像）。

- 战场形象显示尺寸：约 40×47（战斗，代码缩放 0.62）；约 46×55（准备阶段人群，缩放 0.72）；脚底中点是锚点；现在是**正面像、不翻转**。
- 动画建议：idle 2–4 帧、move 4–6、attack 3–4（标命中帧）、hurt 1–2、death 4–6、stun 2、airborne 1–2、skill 3–5（每个兵种的招牌技能，见下表「技能表现」）。

### 2.1 首领的额外需求

- **千垒督军**（石桥镇）：尾节护阵：车首受到的伤害 99% 转给最后一节护卫车；6 节护卫车跟着车首蛇形前进，碾过亡灵会让他们短暂眩晕；每少一节车，车首更快、更狠。打法提示：范围伤害、顺劈能同时打到好几节车；先拆车尾
- **破阵王·铁冠**（狮鹫堡）：列阵冲锋：周期性冲穿亡灵阵线、把人撞飞；铁冠号令：每 9 秒全体人类攻速 +30%；半血时吹响援军号角：4 名王廷侍剑士；王廷血誓：近卫倒下时王廷重剑士变强。打法提示：后排要有人保护；输出越集中越好
